# 第十轮：移除重复宿主入口，精简操作区

版本：`v8.0.15-2.0.0-rebuild.10`，2026-10-06。

## 改动

- 从插件各工作区移除“插件配置”按钮，删除仅用于展示配置并跳转的只读弹窗、开关状态和专用加载函数。
- 从账号页移除“原生登录”入口。配置与 OAuth 登录仍由 CPA 管理中心原生页面承担，未删除插件的 ConfigFields、认证提供能力或宿主接口。
- 手机账号页直接展示“导入”，不再先打开“更多”。按钮可访问名称仍为“导入凭据”，四语言均有短标签。
- 模型页、任务页移除没有实际项目的“更多”按钮和空操作容器。结果页保留有用途的日志/导出菜单。
- 账号页保留数据刷新、额度刷新、导入以及行内账号操作；模型启停需要的 CPA 配置读写、调度提示所需配置读取不受影响。
- 前一轮宿主标题栏 / 悬浮控件避让及第八轮插件积分业务修复保留。

## 验证

新增 9 个浏览器场景：320 / 390 / 1366 宽度 × 独立页面 / CPAMP 标题栏布局模拟 / CPAMC 悬浮布局模拟。每个场景检查四语言：重复配置和登录入口不存在，导入可直接打开，模型与任务没有空菜单，按钮不横向溢出。

前端契约同步改为守护“没有重复插件配置 / OAuth 跳转入口”，不再要求旧的配置跳转按钮存在。原移动弹窗测试直接点击导入，其他草稿/低高度检查保持不变。

- 浏览器：83 个场景 + 普通 HTTP PASS。
- Go race：539 PASS / 1 可选 SKIP；Go vet 与 SDK 固定契约 PASS。
