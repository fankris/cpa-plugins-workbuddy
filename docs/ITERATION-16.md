# Rebuild 16：参考 Manager 优化模型页面

版本 v8.0.15-2.0.0-rebuild.16；2026-10-06。

参考 ithtelab/workbuddy-manager 固定提交 508f803425ce74edc5b7dd6a082ceb415e1c7b62 的 web/app/(main)/models/page.tsx，学习系列/能力筛选、倍率排序、目录首屏状态和元数据分组；不移植独立服务、账号数据库、聊天测试台或另一套配置系统。

## 变化
- 搜索增加系列、倍率和支持档位匹配；保留模型名称和ID搜索。
- 新增系列、图片输入声明、文本输入声明、推理声明、≥128K上下文筛选，可与启停状态/搜索组合。
- 新增来源顺序、名称、上下文降序、倍率升序。倍率只解析明确的x/×非负数字；x0.00保留为有效零，未知和复合表达式排最后，不假定免费或实际账单价格。
- 上方仍统计当前来源全集，表尾显示筛选结果数/来源总数；一键清空所有筛选和排序。条件通过现有会话视图机制保留，官方刷新和语言重挂后不丢失。
- 桌面筛选直接可见；手机高级条件收起，仅在需要时展开。即使收起仍显示筛选指示和表尾清空入口。
- 倍率、输入声明、仅推理、系列分组为标签；支持档位、默认档位与插件固定档位继续分开。手机先看名称与容量，再看能力信息，业务启停按钮保留。
- 容量数字悬停可见原始数值；收紧账号发现来源行；调整窄笔记本列宽及多语言表头换行，避免横向溢出。
- 未选择账号显示选择提示；尚未取得目录和真实空筛选结果区分，不把获取失败当成0模型。

## 不做的推断
不从ID猜测缺失系列，不把supports_images声明等同于实测原生多模态能力，不把未知倍率当0。保留备用目录警告、hy3/hy4固定high标记及保存/运行态确认分离。CPAMP配置通道修复与积分倒计时不回退。
