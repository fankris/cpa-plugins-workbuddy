# Rebuild 13：模型、任务与操作结果

日期：2026-10-06。版本：v8.0.15-2.0.0-rebuild.13。

## 本轮变化
- 模型统计使用当前配置目录或所选账号返回的模型集合，不再始终统计全局目录。未取得数据用「—」，确认空集合才显示 0；搜索过滤不改变来源总数。备用模型目录仍明确提示，不代表验证了推理能力。
- 任务标题和状态合并一行，去掉重复图标；桌面卡片最低高度由 220 降至 190px，手机保持紧凑网格。状态、筛选和单任务按钮共用判断，已领取、锁定优先，锁定任务不会误列为可领取。原有合法任务和批量业务执行保留。
- 本地操作结果支持操作/目标/状态/时间文本搜索，以及全部、需核对、处理中、已结束筛选，可一键清空筛选。需核对包含失败、部分成功、结果未确认；已结束包括已保存，不代表运行态已确认。
- 搜索只针对本次页面会话操作历史，不过滤上方后端请求指标，不替代 CPA 日志。导出仍是全部脱敏记录，表尾明确提示。
- 同源官方刷新和语言切换后保留筛选及会话历史，不重放变更。
- 原版 CPAMC 手机模型和任务页去掉没有业务按钮的空操作行。仅调整插件自身 DOM；其他宿主和独立页面仍保留数据刷新。

## 验证与边界
- TypeScript、构建、77 项 Node 契约、Go 539 PASS / 1 可选 SKIP、vet、SDK/宿主契约、打包失败关闭测试通过。
- 114 组浏览器场景加普通 HTTP。其中原版 CPAMC 前端 27 组（上轮 15 + 本轮 12）；覆盖 1366/390/320 宽度、四语言、实际官方刷新重挂、模型来源统计、任务锁定优先、保存/未确认真实 UI 流程、全量导出及筛选保留。
- 发布 .so 的 C ABI 模拟宿主 10 组通过。
- 文档包含 23 张当前实图，其中 10 张来自未经修改的官方 CPAMC v1.25.3 发布前端，其余为辅助布局模拟或独立页面。业务后端全部为本地夹具。
- 未验收真实 CPA 后端、真实账号或生产业务；未修改生产。CPAMP 仍仅为布局模拟。
- 源码、二进制、离线 HTML 合入一个最新 ZIP；验证后清理临时依赖和测试原始输出，保留紧凑摘要。
