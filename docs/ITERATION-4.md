# 第四轮：账号可见性与模型发现

独立构建 `v8.0.15-2.0.0-rebuild.4`，2026-10-05。SDK 继续固定官方稳定 CPA 8.0.15（ABI 1 / schema 6），CPAMC 参考版本 1.25.3。保留 `/panel`、原有命名、内置业务页布局与四语言跟随；不部署生产。

## 本轮修复

- **账号列表漏项**：原先仅接受带前缀的文件名，会隐藏 `workbuddy.json` 等旧版单文件和明确声明本插件类型的自定义文件名。现在复用现有 family/type 识别，仍拒绝其他 provider，不改名、不另建账号池。
- **模型请求作用域丢失**：`model.for_auth` 与管理页模型查询/刷新保留 SDK 私有 `host_callback_id`，通过 CPA HTTP operation 发起请求。
- **重试和取消**：单账号模型解析总预算 15 秒，包含缓存锁等待、HTTP 与退避；取消可打断退避。429/5xx 使用带状态码的错误分类，支持现有重试规则和 Retry-After，403 不重试。
- **并发和缓存**：按现有凭据缓存键协调；同键普通并发请求复用成功结果，不借用别人的回调上下文。取消等待者不影响所有者。失败不负缓存/不合并失败结果；强制刷新仍每次执行，但只删除自身键，不清掉同区域其他账号。
- **发现结果不再假报成功**：每次结果独立给出 `ok`、`skipped`（固定/静态目录）或 `fallback`（上游发现失败）。保留可用备用目录及警告；前端将 fallback 归为部分完成，而不是成功。

## 不应扩大解释的边界

- 本轮 **未重跑官方 CPA+CPAMC 宿主集成**。第三轮的 12 项真实空宿主验证及官方 SDK HTTP 54 项属于历史证据，不能记为本轮新二进制的运行结果。
- 本轮 ABI 测试调用真正的发布二进制，但宿主回调与上游响应是模拟的，不是真实业务 E2E。
- 未使用真实凭据，未验证真实推理、刷新写回、签到/奖励/跨区业务；不能宣布此前“全部功能失效”已全部解决。
- 仪表盘历史区域汇总诊断仍保留；本轮按次隔离仅用于模型查询/刷新结果。取消表现为带原因的 fallback；缓存命中 source 仍沿用保存的 discovery 标签。
- 未修改生产、云服务、真实账号或回滚卷。合法任务模块保留，不添加虚假完成或权益规避。
