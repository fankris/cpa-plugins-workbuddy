# 第六轮：把屏幕留给操作

版本 `v8.0.15-2.0.0-rebuild.6`。不是只更新截图：已修改 React 页面、响应式布局与交互，重新生成嵌入资产和插件二进制。

## 界面调整

- **单屏工作区**：桌面与手机都使用视口高度布局。分区、常用操作和账号分页留在当前页面；必要时只滚动内容列表，不再让整页越来越长。很小的可视区或展开内容仍允许必要的内部滚动。
- **顶部减负**：手机使用四个短标签，不横向滑动导航；隐藏重复标题和说明；四个统计块合为一条紧凑摘要。低高度触屏横屏收起统计。刷新与额度刷新常驻，其余账号入口放到“更多”。
- **账号不是缩小版表格**：手机改为紧凑卡片，名称、状态、已知余额、区域和操作直接呈现。UID、套餐与详细诊断放入详情；分页始终在底部。
- **每页数量自适应**：观察列表实际可用高度，计算可完整显示的账号数。普通状态下不用滚动就能操作当前页全部账号；筛选或反馈区展开时自动减少当前页条数。桌面保留 8 条分页。
- **搜索常驻，筛选按需打开**：区域、状态、排序不再永久占三行。有活动筛选时显示标记，可重置。
- **模型与任务**：模型手机卡片保留上下文/输出信息，删除重复显示的同名 ID；任务压缩为进度、奖励与直接操作，长说明按需展开。任务规则和连接诊断不再默认撑开。
- **操作反馈去重**：成功结果保留在当前分区的操作栏，不再叠一个遮住分页的成功 toast。异常消息在手机上占用受控的内联区域，不覆盖按钮；其他分区的旧操作不占当前页面。
- **弹窗能操作**：弹窗头和确认按钮固定，只有内容滚动；详情的刷新令牌、签到、启停等操作优先放在前面。用缩短可视区测试确认按钮不被挤到屏幕外。
- **交互缺陷修复**：重选当前任务账号不再清空列表；账号选择组件移到稳定的顶层定义，避免每次父组件重绘就重新挂载。

## 回归结果

- Go race：533 PASS，1 可选导出测试 SKIP；go vet PASS。
- TypeScript / 前端构建 PASS；Node 契约 53 PASS。
- 浏览器既有 30 场景 + 新增移动端 17 场景 = **47 PASS**；实际普通 HTTP 场景 PASS。
- 移动场景涵盖小屏、常规屏、横屏、四语言、筛选、分页、原生 CPA 启停请求、缩短视口弹窗与 iframe。
- 当前 `.so` 无网络模拟宿主 ABI：8 组 PASS，宿主 buffer 遗留 0。
- 新增测试：`tests/iteration-6-browser.mjs`。已有测试仅将刷新按钮定位从旧容器改为新的常驻操作区，未删验收断言。

摘要及移动尺寸测量保存在 `VALIDATION-6.json`；交付 HTML 展示 8 张当前 UI 实图，先展示移动端。每轮仍只保留一个最新 ZIP。

## 不变的边界

CPA 仍负责账号、原生配置、鉴权、调度、刷新、日志与 HTTP；本轮没有引入独立系统，没有更改上游业务协议。本轮没有重跑官方 CPA/CPAMC 实例集成、没有真实账号业务验收，未改生产。模拟 UI 和 ABI 测试不能证明真实推理、奖励或刷新写回已经通过。
