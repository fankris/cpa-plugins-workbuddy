# Iteration 18 — 删除结果页，连接信息归入仪表盘

版本：v8.0.15-2.0.0-rebuild.18。日期：2026-10-06。

## 本轮变更

- 删除“结果”工作区、导航入口、历史表、历史筛选、导出及该页宿主日志快捷入口；没有删除 CPA 原生日志、宿主统计或任务状态。
- 导航保留五项：仪表盘 / 账号 / 模型 / 任务 / 设置。手机网格改为五列，不留下空槽。
- 导航栏不再重复显示连接状态。仪表盘新增连接信息卡，展示最近账号读取的状态、SDK构建目标、v8/v0接口兼容范围与最近成功读取时间。接口路径及说明按需展开，不显示密钥。
- 连接卡复用原账号读取结果，不新增状态轮询或诊断请求。读取中、读取成功、失败、未连接分开；503不会伪装认证失败，401仍走现有鉴权流程。
- `#results` 旧链接和同源宿主内存中保存的 results 选项转向仪表盘；清理旧 logs/resultSearch/resultFilter 临时快照键，避免升级后空白。
- 操作成功/失败/待确认反馈保留在对应业务页面，可打开脱敏详情；同一动作只保留最近反馈，不保留旧的100条结果列表。最多20个动作摘要，仍为身份隔离的内存状态，不是审计数据库。
- 更新两条菜单注册轨道的共用说明，去掉 results。保留原命名和 /panel。

## 未改变

保留双来源账号模型目录、CPA模型配置、真实积分/到期倒计时、合法任务与插件专属设置。模型目录不自动扩充CPA路由，CodeBuddy Intl目录仍未验证。未修改生产、云端或真实账号。

SDK显示的是构建目标，不是运行宿主版本探测；v8/v0是接口兼容范围，不代表两条接口都已探测成功。连接成功只说明最近账号读取成功，不保证所有腾讯业务可用。
