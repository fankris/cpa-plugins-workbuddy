# rebuild27 — 全工作区可读性与空间重排

本轮覆盖账号、仪表盘、模型、任务、插件设置，以及账号详情、模型详情、来源选择弹窗。不是浏览器 zoom，也不是只在页面末尾强制放大几处文字。

## 字体体系

将既有CSS中的微型字号迁移到共享文字变量，保留明确层级：

|层级|字号|
|---|---|
|主标题|18–22px|
|模型名称、设置项标题|16px|
|主要内容、账号名称、参数值|14–16px|
|辅助说明与时间|12–13px|
|徽章|12px，配14px图标|
|关键统计值|22–26px|
|手机输入控件|16px|

本地真实浏览器审计显示，原版五页均有小于12px的可见文字，最低8px。新版在5种外窗宽度×4种语言×5页的100组页面检查中，可见文字最低12px；另检查5组弹窗。宿主自身的导航和悬浮按钮不属于插件，不改写它们。

## 布局不是简单放大

- **账号**：单按钮操作列由模拟桌面实测260px压缩至约132px；余额及到期信息获得空间。手机指标改为2×2，避免缩字或截断长标签；账号分页读取CSS行高，并用剩余高度展示下一条可滚动记录，消除旧向下取整留下的大片空框。
- **模型**：宽屏使用双列信息块，超宽窗口按可读最小宽度增加列数；中等宽度保留紧凑表格，手机保持单列。减少短参数横跨长行的空白。CN/Intl、Dynamic/Custom、能力声明范围及未知状态逻辑不变。窄屏来源/刷新操作采用有可访问名称的图标按钮，避免工具栏无必要地换行。
- **仪表盘**：连接信息与指标置顶，到期账号和需关注账号在宽屏并列；内容按实际数据高度排布，不拉伸少量记录撑满卡片。无数据时不补造内容来填空。
- **任务**：取消虚高卡片；修正标题/状态/进度/奖励/动作的布局。卡片按内容计算行高，避免大字按钮超出边界、被下一张卡片遮挡。筛选标签可换行，不以微型文字换取一行。
- **设置**：去掉重复“插件配置”标题；自动业务/调度策略、账号维护/最近旅行检查按两条独立纵列排列，不强制左右卡片等高。作用范围与运行态并排，手机回到单列。开关、未知运行态及维护确认行为不变。
- **详情弹窗**：同步字体层级、缩减重复留空，长字段保持换行和滚动可达。

## 验证

- Go race 615 PASS，1 optional SKIP；go vet、TypeScript、构建通过。
- Node 143 PASS；新增字号下限、分页行高来源及设置回调保留契约。
- 本轮浏览器169组：既有64组回归，加105组可读性/布局检查。
- 可读性覆盖外窗320、390、1024、1366、1920宽度；简体、繁体、English、Русский。官方CPAMC侧栏占宽后，插件自行响应剩余区域。
- 检查可见文字字号、页面/内容横向溢出、主数据字号、账号操作列宽，以及任务按钮不超出卡片。详情与来源弹窗同样检查。既有回归包含深色模式、只读操作、配置确认、地域业务隔离等。
- 35张当前构建截图；31张来自原版CPAMC前端，另4张独立/CPAMP夹具。账号、目录与业务数据都是模拟。
- 发布.so通过C ABI模拟宿主验证。没有把这些结果说成完整CPA生产或真实腾讯账号验收。

原始前后测量在本地 validation/iteration-27；可携带摘要见 READABILITY-27.json，完整本轮验证摘要见 VALIDATION-27.json。只保留一个最新ZIP；生产未改动。

**取舍**：优先文字可读、操作完整。必要时列表滚动，不再以8–11px字强行塞进一屏；自然的数据留白保留，不使用虚假指标或装饰性内容填满页面。
