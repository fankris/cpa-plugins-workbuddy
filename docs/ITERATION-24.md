# rebuild24：国内/国外业务能力隔离

日期：2026-10-07。CPA 8.0.15；Go 1.26；Linux amd64 / glibc≥2.34。生产未改动。

## 本轮实现

|能力|国内|国外|
|---|---|---|
|签到及签到状态|支持|本地跳过，无上游请求|
|成长任务、真实进度领奖、旅行|支持|本地不适用|
|试用申请|不适用|需用户单独确认；资格由上游判定|
|地区激活诊断|不适用|仅显式 GET 查询；不注册、不选地区、不领取试用|
|积分、模型、令牌维护、CPA 管理|保留|保留，权限/套餐/凭据不足如实返回|

WB/CB 仍是同区域入口，默认 WB。公开渠道仅 cn/intl；原登录协议、凭据来源和既有维护政策不因渠道合并改变。

1. 统一 capabilities 元数据。supported 与 eligibility 分开；国外账号不再天然 trial_eligible。未看到试用套餐不等于从未领取。
2. 国外签到拦截覆盖底层函数、冷缓存、强制刷新、旧缓存快照与账号展示。单账号签到仍采用兼容的批量结果结构，明确 skipped；任务/旅行/试用不适用返回 unsupported_region / HTTP422。
3. 修复国内任务非 web 请求缺少 Bearer 授权头的问题。新增实际请求头断言；请求经 CPA 原生 HTTP，绑定插件生命周期并设置15秒超时。
4. 自动旅行脱离旧 growth_auto 分支；checkin_auto=false 时 travel_auto=true 仍执行。采用现有每日09:00/21:00宿主本地时间计划，最多4并发，跳过国外及禁用账号，与手工任务共享账号锁。停机取消请求、排空工作器。没有伪造活动上报。
5. last_travel_run 展示真实内存执行汇总，不用“开关已开”冒充执行成功。记录只持续至插件重载；缺失字段显示未知，明确 null 才表示本次启动无记录。检查成功可能是已在旅行或达到日限额，不保证每次获得积分。
6. 旅行目的地配置缺失时不再编造 location_id=1；未知状态不报告成功。
7. 国外积分优先 /billing/meter/get-user-resource，仅 HTTP404/405 或业务404回退同域 /v2 路径。认证失败、限流、服务错误、解析失败不触发路径回退，不跨区域。其他计费路径未无依据重写。
8. 激活诊断采用 Manager 的现有 GET 合约：HTTP成功下业务0/200表示已注册、500表示需完成地区注册；HTTP失败/缺失或其他代码为未知。它不证明可领试用；上游合约变化仍需真实账号复核。
9. 试用单独确认，already_claimed 不误报失败；试用处理不再隐式调用生命周期维护。GET积分保持只读，POST /refresh 仍是独立、有明确确认的维护操作。历史耗尽账号保留禁用行为不变，展示名称改为 disable_retained，不推断物理删除。
10. 混合勾选确认显示执行/跳过数；国外签到不发送请求，结果保留跳过项。五工作区、原 /panel 双菜单、模型来源选择不改路由等既有约束不变。
