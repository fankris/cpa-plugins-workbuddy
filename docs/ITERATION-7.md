# 第七轮：PC 专项优化

版本：`v8.0.15-2.0.0-rebuild.7`。此前桌面仅做了视口内布局，本轮补齐桌面密度、操作分组、详情对照和专项验收；保留第六轮手机布局。

## 实际修改

- 桌面标题与工具栏收紧，去掉重复说明。设置、原生登录、额度刷新、导入保持明确分组，不新增应用外壳。
- 四个大统计块变为紧凑的一行。总数、可用、需要关注支持直接筛选；汇总计数和筛选使用同一判断函数，不出现“数字是 2，点进去只剩 1”的错位。
- 账号表格默认行高约 46px（窄屏/长语言可略增），列宽和行内按钮统一，选中与悬停状态可辨。操作列保持可见，不依赖 hover 才出现。
- 默认每页 8 条；新增桌面每页 8 / 12 / 20 条选择。主动增加条数时允许列表内部滚动，分页仍固定。
- 桌面详情改为双栏：左侧账号常用操作、额度与套餐，右侧宿主诊断与本地计数。增加上/下一个账号，按当前筛选排序切换，无需关闭重开；业务请求忙碌时禁止切换。
- 模型、任务、操作结果同步调整密度；手机卡片、自适应分页与低高度横屏规则不受桌面规则覆盖。
- 修复重复点击同一账号的“任务与活动”入口后列表被清空却不重新加载的问题。本轮没有改变 CPA 存储、调度或上游业务协议。

## 实测范围

Chromium 模拟数据测试覆盖 **1024×768、1366×768、1440×900、1920×1080**；每种尺寸都测试简中、繁中、英文、俄文。

- 初始普通账号页面：默认 8 条账号、全部行内操作和分页完整可见，不需要整页或列表滚动，无水平溢出。
- 首个账号约从 y=275px 开始。1366×768 同源 iframe 场景保留 80px 宿主工具栏避让，首个账号约从 y=343px 开始，8 条仍全部可见。
- 1366×768 模拟账号详情中，两栏同时显示且正文不需要滚动；包含更多套餐/诊断项的真实账户仍可能需要内部滚动。
- 指标快速筛选、每页条数切换、选中高亮、详情内切换账号、重复任务入口均通过交互检查。
- 这不是所有屏幕/所有数据量“永远零滚动”的承诺。长错误、大量套餐、展开说明和主动选择 20 条可能需要局部滚动。
