# CPA 的 WorkBuddy 扩展插件

**当前源码：`v8.0.15-2.0.0-rebuild.19` · 2026-10-06。** 以 CPA 为主体，选择性参考 WorkBuddy Manager 的业务与交互，不移植独立管理架构。

使用 CPA 8.0.15 SDK（ABI1 / schema6），保留原 provider/auth 身份、WorkBuddy 菜单和 `/panel`。每轮只保留一个最新 ZIP，包含源码、Linux amd64插件、带实际截图的离线HTML、许可证与校验清单。

## 本轮

**本轮重新设计模型中心：按渠道来源账号聚合已获取与自定义模型，逐模型标注来源和渠道，参数差异保留详情；查看来源不改变实际路由。**

保留上一轮：删除结果页，将连接信息放到仪表盘。 原结果页导航、表格、筛选与导出均移除；业务页面保留最近动作的成功/失败/待确认反馈及脱敏详情。旧链接及宿主记住的 results 页面自动迁移到仪表盘。

见 [本轮实现](docs/ITERATION-19.md)、[验证](docs/VALIDATION-19.json)、[职责划分](docs/FEATURE-MATRIX.md)。

## 五个工作区

| 工作区 | 职责 |
|---|---|
| 仪表盘 | 连接状态、SDK目标、接口兼容范围与路径、最近成功读取时间；积分和临期汇总 |
| 账号 | 搜索/筛选、分页、多选、详情、导入、原生账号启停和令牌刷新；积分、签到及符合条件的试用 |
| 模型 | 每渠道一个来源账号的模型聚合；动态/自定义标注、渠道证据与逐来源详情；保留原生配置读回 |
| 任务 | 国内合法任务、真实进度、接受任务、领取已完成奖励、批次状态、协作取消与旅行 |
| 设置 | 插件自动业务开关、运行态核对、可选临期积分账号调度，不重复CPA通用配置 |

连接卡复用账号读取结果，不新增诊断轮询；SDK是构建目标，不是实测宿主版本。原生CPA日志和统计不受结果页删除影响。

## 保留的能力及边界

- 模型目录读取企业接口与 `/v3/config`，来源冲突明确显示，未知不填成已知。完整目录不自动注册或启用CPA模型；CodeBuddy国际目录尚未验证。
- CPAMP原生配置只在读取阶段协商v8/v0路径，写入/读回锁定路径，不因失败重放变更。
- 最早到期批次积分与一位小数天数独立于7天内汇总。倒计时基于服务器校准快照，不额外轮询账单。
- 积分临期优先仅在CPA给出的同优先级可用候选中选择账号，不控制账号内部套餐扣减顺序。
- 四语言：简中、繁中、EN、RU；跟随同源宿主语言与主题。手机五项导航、局部滚动、按需筛选，PC紧凑列表与双栏账号详情。
- 不新增账号数据库、登录系统、网关或通用配置编辑器。CPA负责凭据持久化、鉴权、原生日志、HTTP与流式桥接。

## 状态与隐私

筛选、任务视图及未提交导入草稿仅在身份/路径隔离的父窗口内存中恢复；导入草稿不写localStorage或sessionStorage。父页重载或关闭后丢弃。手动管理密钥沿用标签页sessionStorage，不抓取宿主未记住的内存密钥。确认动作不自动重放；中断且无服务端运行标识的反馈改为待确认。原生凭据刷新响应丢弃，只保留安全摘要。

## 迁移注意

- 默认 `scheduler_mode=host`；`builtin` 和历史 `off` 仍委托轮询，off不是关闭插件；`credits` 表示选中账号，不是余额排序。
- `token_keepalive`、`travel_auto` 默认false。`checkin_auto`、`lifecycle_auto` 保留true默认值；不希望自动动作时，首次加载前显式关闭。
- `growth_auto` 强制false，历史合成活跃接口返回410。保留合法任务；不添加虚假活跃、伪造完成、批量注册或额度规避。
- 原生GET/merge/PUT保留未知配置字段，但不同管理者之间不具备原子写事务。
- 取消任务只能阻止后续工作，不能撤销已发出的上游动作。任务运行态仅内存保留，终态约15分钟。

## 构建、预览与安装

需要Go1.26、C编译器和Node/npm。源码包含已编译前端资产，修改前端后必须重建。

```sh
make frontend
make frontend-test
make test
make build
python3 tests/preview_server.py --bind 0.0.0.0 --port 8080
```

预览后端始终是模拟，不是真实账号。浏览器测试另需Playwright Chromium及系统依赖。

安装前备份插件、CPA配置和auth数据。在隔离CPA8.0.15实例中把workbuddy.so放入实际配置的插件目录，通过原生管理加载。包仅适配Linux amd64、glibc≥2.34，非ARM/Windows/musl通用包。回退需恢复自己的二进制/配置备份；不能撤销已发生的业务动作。
