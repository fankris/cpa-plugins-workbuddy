# CPA 的 WorkBuddy 扩展插件

**当前源码：`v8.0.15-2.0.0-rebuild.14` · 2026-10-06。** 一切以 CPA 为主体；WorkBuddy Manager 仅选择性参考业务流程和交互，不照搬其独立管理系统。

使用官方稳定 CPA 8.0.15 SDK（ABI 1 / schema 6），管理界面对照 CPAMC v1.25.3。保留 provider/auth 身份与 `/panel`。保留最新源码，每轮只留一个最新 ZIP（源码 + Linux amd64 插件 + 含 UI 截图的离线 HTML），临时文件打包后清理；[本轮修复](docs/ITERATION-14.md)、[验证边界](docs/VALIDATION.md)、[职责划分](docs/FEATURE-MATRIX.md)。

## 本轮：单屏操作工作区

手机顶部压缩为短标签、常用操作和一条摘要；搜索常驻，筛选按需展开。账号卡片按可用高度分页，状态、余额与操作直接可见。模型、任务和弹窗也同步紧凑化。桌面同样限制在视口内，必要时只滚动内容区。详见 [本轮测量与限制](docs/ITERATION-14.md)。

## 保留的 PC 优化

紧凑汇总支持直接筛选；表格与行内按钮对齐；每页 8/12/20 条；账号详情左右双栏，可直接切换上/下一个账号。四种桌面尺寸与四语言通过专项检查，手机布局保留。

## 六个工作区

| 工作区 | 本版实现 |
|---|---|
| 账号与套餐 | 搜索、区域/状态筛选、分页、多选、额度与套餐摘要、账号详情、凭据导入；原生登录入口；账号启停和 token 刷新调用 CPA 原生管理接口；额度刷新、签到、符合条件的试用领取保留插件业务实现 |
| 模型诊断 | 模型目录、按账号发现模型、强制刷新发现、启停模型、保留未知配置字段；不虚构上游未提供的逐模型额度 |
| 任务与活动 | 国内任务列表、真实进度、领取任务、领取已完成奖励、接受可用任务的后台批次、状态轮询与协作取消、旅行操作；跨区能力明确限制 |
| 诊断与操作结果 | 最近操作、成功/失败/部分成功/已领取/取消请求/结果未确认区分、脱敏详情和导出、原生日志入口；本地用量计数清理明确不等于恢复上游额度 |

以上多项业务原本就存在；本版主要是完整重组交互、原生能力接入和正确性修复，不把全部旧能力宣传成新增。

界面按 CPAMC 内置业务页组织：单层分区标签、紧凑统计与表格、行内操作和持续结果提示，无重复标题栏、⌘K 或底部浮动导航；支持深色与移动端。前端源代码为 React/TypeScript，编译资产内嵌于插件，不依赖运行时 CDN。

## CPA 已有的能力不再另建

账号持久化使用宿主 auth；鉴权由 CPA 管理中间件执行；原生配置页负责插件设置编辑。插件设置弹窗只读。OAuth、日志入口跳转 CPAMC，账号禁用/启用和手动 token 刷新走 native v8；请求与流式传输使用宿主 HTTP/stream bridge，统计上报使用宿主接口。未新增独立账号池、网关、管理密钥库、统计数据库或通用重试系统。

WorkBuddy 专有额度、模型发现缓存与业务任务状态仍由插件处理；本地结果列表不是完整审计数据库，原生日志也不等于完整历史统计数据库。

## 语言、主题及敏感状态

- 跟随同源 CPAMC 的 `zh-CN`、`zh-TW`、`en`、`ru`；同源宿主主题被动跟随。
- CPAMC 1.25.3 切换语言会销毁并重建 iframe。本版用插件专属、按路径和管理身份隔离的**父窗口内存快照**保留筛选、导入草稿、选中账号、任务运行等视图状态。刷新整个父页或关标签即丢弃。
- 导入草稿不写 localStorage/sessionStorage。未提交确认不会自动重放；重建时无服务端运行标识的未完成操作变为“结果未确认”。
- 没有虚构跨域 postMessage 协议。跨域无法读取语言时明确提示；同源未“记住密码”的宿主内存密钥不可继承时，提供手动管理密钥输入。手动密钥沿用标签页 sessionStorage；这不同于导入草稿的纯内存保存。
- 原生刷新接口可能返回 auth；UI 丢弃凭据响应，只保存安全结果摘要。

## 迁移前必读

| 配置/行为 | 本版规则 |
|---|---|
| 未配置 `scheduler_mode` | 默认 `host`，交回 CPA 已配置的调度策略；不再隐式覆盖宿主策略 |
| 显式 `builtin` 或 `off` | 保留历史 round-robin 委托；**`off` 不是关闭请求/停止插件** |
| 显式 `credits` | 保留活动账号选择逻辑，**不是按积分余额排序**；面板“选择账号”仅在该模式有对应路由意义 |
| 未配置 `token_keepalive`、`travel_auto` | 默认 false，须主动开启；CPA 自身凭据刷新仍由 CPA 管理 |
| `growth_auto` | 始终 false，旧配置无法重新启用合成活跃上报；`POST /tasks/light` 返回 410 |
| `checkin_auto`、`lifecycle_auto` | 延续默认 true；如不希望自动业务动作，安装前在原生配置中显式关闭 |
| 配置更新 | native GET/merge/PUT 保留未知字段；本页面写入串行化，但**不同管理者并发写入不具备原子性** |
| 任务取消 | 只阻止后续批次，不撤销已完成或在途上游动作；运行状态仅内存保存，终态保留约 15 分钟 |

保留合法任务模块；不实现虚假活跃、伪造完成、批量注册或额度规避。清理本地日用量计数只清理记录，不恢复真实配额。

## 构建和验证

要求 Go **1.26.0**、C 工具链、Node.js/npm。源码已含编译后的浏览器资产；修改前端后必须重新构建，再编译 `.so`。

```sh
make frontend                 # npm ci + TypeScript + esbuild
make frontend-test            # 前端/原生配置契约
make test                     # Go race 回归
make build                    # 当前平台 c-shared
python3 tests/preview_server.py --port 8080  # 仅本地演示夹具
# 另开终端，安装 Playwright 浏览器及所需系统库后：
node tests/rebuild-browser.mjs
```

正式构建命令及精确版本、源码来源、依赖许可证见 `docs/PROVENANCE.json`、`THIRD_PARTY_NOTICES.md`。夹具预览始终显示“演示数据”，不得把夹具账号当作真实联调。

## 安装与回退

1. 先备份现有插件二进制、CPA 配置和 auth 数据。不要重命名既有账号文件，不要覆盖生产密钥。
2. 确认宿主为 CPA 8.0.15、平台匹配；先在**隔离测试实例**内试装。使用 CPA 原生插件配置/管理方式，把 `workbuddy.so` 放进该实例实际配置的插件目录并启用 `workbuddy`。
3. 重载/重启该隔离实例，确认插件注册成功、schema 6，CPAMC 插件资源入口可打开原 `/panel`。不要添加第二个网关。
4. 本版默认值有变化，按上表显式核对。先验证空账号页面，再由账号所有者使用测试账号验证推理、刷新与业务操作。
5. 回退时恢复备份二进制和必要的配置，再重启；更换二进制不会撤回已经发出的上游操作。旧进程内任务状态不能迁移。

**本次没有替换新加坡生产插件，也没有改动生产账号、配置、密钥或美国回滚卷。**
